# ArtVision Miami Art Week Opportunities Database

Running database of free (and select prestigious fee) opportunities to exhibit digital or physical art during Miami Art Week, with emphasis on Web3/crypto related organizations or curators.

For the ArtVision brand podcast special segment.

**How to use:** Search the JSON database for keywords like "MIAMI", check status (open/closed), deadlines, and URLs.

Updated as of November 26, 2026.

See `narrative_script.md` for the conversational podcast-style script.
See `opportunities_database.json` for the searchable entries.
